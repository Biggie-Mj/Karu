# Démarrer avec Karu

1. Déposer tous les fichiers de ce dossier dans votre dépôt GitHub.
2. Activer GitHub Pages depuis Settings → Pages.
3. Ouvrir l’adresse dans Safari, attendre « Hors ligne prêt », puis Partager → Sur l’écran d’accueil.

Le guide complet est `README.md`. Les 49 tests et les limites de validation sont détaillés dans `VERIFICATION.md`. Les décisions du MJ restantes figurent dans `REGLES-ET-ARBITRAGES.md`.

Les quatre fonds WebP et les vingt icônes PNG transparentes sont déjà intégrés. Leurs fichiers sont recensés dans `MANIFESTE-ASSETS.json`. Aucune compilation ni clé d’API n’est nécessaire.

Les sauvegardes restent sur l’appareil : penser à exporter le JSON depuis les réglages.
